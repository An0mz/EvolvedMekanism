# Evolved Mekanism APT Only Neo: Documentation

Docs for the NeoForge 1.21.1 version (Mekanism 10.7, Iglee Lib 1.2).

- **[APT](apt.md)**: the Antimatter Protomolecular Transmutator multiblock. How to build it, how it works, Supercharging Elements, config.
- **[Machines](machines.md)**: the Alloyer, the Chemixer and the Alloying Factories.
- **[Materials](materials.md)**: Better Gold, Plaslitherite, Refined Redstone, the Nether and End uranium ores, the new alloys and circuits.

JEI shows every recipe in this mod. The recipes listed in these docs are the defaults and can be changed with datapacks or KubeJS.

## Progression at a glance

```
Atomic Alloy ──(Metallurgic Infuser + Uranium)──────────► Hypercharged Alloy ─► Overclocked Circuit
Hypercharged ──(Antiprotonic Nucleosynthesizer)─────────► Subatomic Alloy ────► Quantum Circuit
Subatomic ─────(Metallurgic Infuser + Better Gold)──────► Singular Alloy ─────► Dense Circuit
Singular ──────(Metallurgic Infuser + Plaslitherite)────► Exoversal Alloy ────► Multiversal Circuit

SPS Casing ──(Nucleosynthesizer)──► APT Casing ──► build the APT ──► Better Gold
Singular Alloy + Dense Circuit ──► Chemixer ──► Plaslitherite
```
